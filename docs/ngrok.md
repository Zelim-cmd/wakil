# Адрес в интернете (ngrok) — для официального WhatsApp и Instagram

Meta присылает сообщения клиентов на адрес в интернете, а Вакиль работает на вашем компьютере. Бесплатная программа **ngrok** даёт компьютеру постоянный адрес вида `https://ваше-слово.ngrok-free.app`.

Для WhatsApp по QR-коду ngrok **не нужен**.

## Один раз

1. Зарегистрируйтесь на https://ngrok.com (бесплатно).
2. Установите ngrok:
   - **Mac:** в Терминале `brew install ngrok`. Если Homebrew нет, скачайте с https://ngrok.com/download и перенесите файл `ngrok` в папку `/usr/local/bin`;
   - **Windows:** скачайте с https://ngrok.com/download, распакуйте `ngrok.exe` в любую папку и добавьте её в PATH. Или положите `ngrok.exe` в `C:\Windows`.
3. Подключите аккаунт. В кабинете ngrok откройте **Your Authtoken**, скопируйте команду и выполните её в Терминале/PowerShell:
   `ngrok config add-authtoken ВАШ_ТОКЕН`
4. Получите **постоянный бесплатный адрес**: кабинет ngrok → **Domains** → создайте домен. Он выглядит как `что-то.ngrok-free.app`.
5. В панели Вакиля: **Подключения → Адрес в интернете** → вставьте `https://что-то.ngrok-free.app` → **Сохранить**.

Готово: **Вакиль сам запускает ngrok** вместе с собой и перезапускает, если тот упадёт. На странице «Подключения» видно, работает ли он.

## Проверка

Откройте в браузере `https://что-то.ngrok-free.app/webhook/whatsapp`. Сначала ngrok может показать страницу-предупреждение: нажмите **Visit Site**. Потом должно показать `forbidden`: это нормально, значит адрес доходит до Вакиля.

## Если ngrok не подходит

Подойдёт любой туннель на порт **8791** (вебхуки), например **Cloudflare Tunnel** со своим доменом. Запускайте его сами и впишите адрес в панели. Порт **8790** (панель) в интернет **не открывайте**.
