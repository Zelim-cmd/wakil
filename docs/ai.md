# ИИ: подписка или ключ

Вакиль одинаково работает с любым из вариантов. Переключается в «Подключения → ИИ».

| Вариант | Оплата | Скорость ответа | Качество |
|---|---|---|---|
| **Claude по подписке** (Claude Code) | Подписка Pro/Max | ~8–12 с | Лучшее для этой задачи (рекомендую) |
| **ChatGPT по подписке** (Codex) | Подписка Plus/Pro | ~15–20 с | Хорошее |
| **Ключ API** (Anthropic, OpenAI, Gemini, OpenRouter, DeepSeek…) | За каждый запрос | ~5–10 с | Зависит от модели |

## Как это работает по подписке

На компьютере установлена программа Claude Code (или Codex), в которой выполнен вход в ваш аккаунт. Вакиль запускает её на каждый ответ, **отключив ей все инструменты**: ИИ не может ни читать файлы, ни выполнять команды, ни ходить в интернет. Он только пишет ответ. Это важно, потому что сообщения клиентов — чужой текст.

Модели (Claude):
- `sonnet` — для ответов клиентам (по умолчанию): быстро и умно;
- `opus` — для разбора дня и аналитики: умнее, но тратит больше лимита;
- `haiku` — самая быстрая и экономная, если лимита не хватает.

## Лимиты

У подписок есть лимит запросов на несколько часов. Примерный расход:
- одно сообщение клиента (или пачка сообщений подряд) — 1 запрос;
- разбор дня — 1 большой запрос вечером;
- чат «Обучение» и аналитик — по запросу.

Если лимит кончился, клиент получит одно вежливое сообщение «менеджер ответит», а вам придёт уведомление. На странице «Аналитика → Работа ИИ» видно, сколько было сбоев из-за лимита.

## Правила сервисов

Подписки Claude и ChatGPT предназначены для личной работы человека. Автоответы клиентам — серая зона их правил, и при большом потоке аккаунт могут ограничить. Если бизнес растёт, переходите на **ключ API**: это официальный способ для программ, оплата по факту (за обычный диалог с клиентом — центы).

## Ключ API

1. Получите ключ (ссылка появится в панели при выборе сервиса).
2. «Подключения → ИИ» → выберите сервис → вставьте ключ → «Проверить связь».

Сервисы, совместимые с OpenAI (OpenRouter, DeepSeek, Gemini, локальные Ollama/LM Studio), подключаются через пункт «Другой сервис» с адресом и ключом.

## Если ChatGPT (Codex) пишет ошибку модели

Вакиль запускает Codex без ваших личных настроек (`--ignore-user-config`), чтобы не подхватить модель, недоступную по подписке. Если нужна конкретная модель, впишите её в поле «Модель». Пустое поле — модель по умолчанию для вашей подписки.
