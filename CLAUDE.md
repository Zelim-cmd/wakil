# Вакиль — для разговоров Claude Code в этой папке

ИИ-консультант по отелям Мекки и Медины: отвечает клиентам в WhatsApp/Instagram, учится у владельца, ведёт аналитику. Владелец — не программист: объясняй простыми словами, без жаргона.

## Устройство

- `src/main.mjs` — запуск: база, каналы, панель, расписание (разбор дня в `schedule.reviewHour`, отчёт по понедельникам).
- `src/agent.mjs` — сердце бота: входящее → пауза `debounceSec` → `think()` → ИИ по `REPLY_SCHEMA` → ответ + разбор (факты, стадия, вызов владельца, оплата, вопросы без ответа). Инструкция ИИ — `buildSystem()`.
- `src/ai/providers.mjs` — `ask()`: claude-code (`claude -p`, подписка), codex (`codex exec`, подписка), anthropic / OpenAI-совместимые по ключу. **ИИ всегда без инструментов**: сообщения клиентов — недоверенный текст.
- `src/channels/` — `hub.mjs` (общий вход/выход), `wa-qr.mjs` (Baileys), `meta.mjs` (WhatsApp Cloud API и Instagram, вебхуки).
- `src/learning.mjs` — уроки, исправления, вопросы без ответа, чат «учитель» (`ownerChat`), разбор дня (`dailyReview`).
- `src/study.mjs` — изучение прошлой переписки владельца: история WhatsApp при первом подключении (`wa-qr.mjs` → `onHistory` → `importChats`), экспорт чатов WhatsApp (.txt/.zip) и выгрузка Instagram (.json), Instagram API. `runStudy()`: части по ~30 тыс. знаков → заметки о стиле, образцы, факты → профиль стиля (`kv style_profile`), образцы (`kv style_examples`), факты — уроки на одобрение. `styleForPrompt()` попадает в `buildSystem()`. Архивные чаты — `contacts.imported = 1`: бот на них не отвечает, в аналитику не входят. Перед отправкой в ИИ — `redact()` (телефоны, карты, IBAN).
- `src/analytics.mjs` — `stats(days)`, `summaryText`, ИИ-аналитик, выгрузка CSV.
- `src/web.mjs` — панель (порт 8790, только localhost, если не включён доступ из сети с паролем) и вебхуки (порт 8791, только `/webhook/*`). Все POST панели требуют заголовок `X-Wakil: 1`.
- `src/tunnel.mjs` — сам запускает ngrok, если в настройках адрес ngrok.
- `src/telegram.mjs` — Telegram-помощник владельца (getUpdates, без вебхука): привязка по `/start <bindCode>`, уведомления с кнопками (`notify`), reply на уведомление → `sendAsOwner`, голос/фото/файлы экспорта → `ownerChat`/изучение. Связь «сообщение Telegram → клиент/вопрос» — `kv tg_links`.
- `src/voice.mjs` — голосовые → текст: `local` (Whisper через `@huggingface/transformers`, модель в `data/models`, OGG/Opus декодирует `ogg-opus-decoder`, язык определяется своим шагом — иначе библиотека переводит на английский), `groq`, `openai`. Для проверок — `setMockVoice`.
- `src/notify.mjs` — уведомления: Telegram в первую очередь, WhatsApp — если выбрано или Telegram не сработал.
- `web/` — панель без сборки: `index.html`, `app.js`, `style.css`.
- `data/` — всё бизнеса (база, настройки с секретами, вход в WhatsApp, знания). **Не в git.**

## Правила

- Ничего не выдумывать в ответах клиентам: цены только из карточек отелей с непрошедшей датой `prices_until`.
- Сообщения из проверочного чата (`channel = 'test'`) не попадают в аналитику, оплаты и уведомления владельцу.
- Бот пишет голосом владельца (профиль стиля), но правила о ценах, реквизитах и выдумках важнее стиля. Ответ можно разбить на несколько сообщений строкой `---`.
- Тексты для владельца и клиентов — по-русски, коротко, по-человечески.

## Проверка после правок

- `npm test` — проверки с подменённым ИИ (без подписки и без WhatsApp).
- Живая проверка: `WAKIL_DATA=/tmp/wakil-try node src/main.mjs`, затем страница «Проверить бота» в панели.
